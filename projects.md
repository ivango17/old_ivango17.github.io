# My Projects

Over the last few years, I have been fortunate enough to work on a variety of 
bioinformatics projects. Here are a few I want to highlight.


## Single-cell Multiple Kernel Learning (scMKL)

Single-cell Multiple Kernel Learning (scMKL) is a published supervised 
classification framework that is interpretable and capable of integrating 
across several several omics types. Leveraging Celer and AnnData objects, 
scMKL is scalable and has been packaged and documented for easy implementation 
by researchers everywhere!

## Bioinformatic Challenges

[Rosalind](https://rosalind.info/problems/locations/) is an excellent resource 
for exposing bioinformaticians to new problems and strengthening their skills. 
The bioinfo_toolbox.py module in 
[this](https://github.com/ivango17/Bioinformatics_Challenges/tree/main) 
repository contains many of the functions need to solve common bioinfomatic 
problems. There are also scripts in this repository for solving several of the 
harder Rosalind challenges. 


## Demultiplex

Multiplex seqeuncing data requires workflows to demultiplex reads before 
alignment. For paired-end sequencing data, this can be done with 
demultiplexing.py. The code repository found 
[here](https://github.com/ivango17/Demultiplex) 
also contains unit tests and Q-score distribution visualizations.


## RNA Quality Assessment 

To analyze bulk RNA-seq datasets, one must evaluate Q-scores, trim reads, and 
align sequences to a reference genome. Source code to do all of this can be 
found [here](https://github.com/ivango17/QAA) as well as a data summary report 
example.
